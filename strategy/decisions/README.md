# strategy/decisions/

Architecture Decision Records (ADR) — zaznamy o klicovych architektonickych a strategickych rozhodnutich.

## Co je ADR

ADR je kratky dokument zaznamenavajici dulezite rozhodnuti, jeho kontext, alternativy a duvody. Slouzi jako institucionalni pamet firmy.

- Sablona: [adr-template.md](../../templates/_meta/adr-template.md)
- Status: `proposed` → `accepted` → `deprecated` / `superseded`
