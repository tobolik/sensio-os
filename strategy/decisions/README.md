# strategy/decisions/

Architecture Decision Records (ADR) — záznamy o klíčových architektonických a strategických rozhodnutích.

## Co je ADR

ADR je krátký dokument zaznamenávající důležité rozhodnutí, jeho kontext, alternativy a důvody. Slouží jako institucionální paměť firmy.

## Konvence

- Číslování: `adr-NNN-nazev.md` (třímístné číslo)
- Šablona: [adr-template.md](../../templates/_meta/adr-template.md)
- Status: `proposed` → `accepted` → `deprecated` / `superseded`
